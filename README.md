# QuickNotes App

QuickNotes is a simple note-taking web application that allows users to create, organize, search, and delete notes. Notes can be categorized as Personal, Work, or Study. The application uses HTML, CSS, and JavaScript, with localStorage to save notes in the browser.

## Features

- Add notes with a category.
- Organize notes into Personal, Work, and Study.
- Search notes by their text.
- Delete individual notes.
- Validate empty notes and notes longer than 200 characters.
- Display the total number of notes.
- Save notes in the browser using localStorage.
- Responsive layout for different screen sizes.

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Add, search, and manage your notes.
